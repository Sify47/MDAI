🏗️ البنية

هندسة المشروع

VITA مبني على بنية متطورة تفصل بين الواجهة الأمامية والخلفية باستخدام أحدث التقنيات.

📱

الواجهة الأمامية (Frontend)

Flutter / Dart - تطبيق متعدد المنصات (Android, iOS, Web, Windows, macOS, Linux)

  • بنية MVVM مع Provider لإدارة الحالة
  • شاشة رئيسية معاد تصميمها (MVVM + مكونات)
  • تحميل متوازي للبيانات (Future.wait)
  • نظام تخزين مؤقت (Caching) بفترة صلاحية 5 دقائق
  • مكونات Skeleton Loading للتحميل
  • دعم RTL الكامل للغة العربية
  • Animations متقدمة (Lottie, Shimmer, Staggered)
Flutter 3.x Dart Provider Firebase
⚙️

الخلفية (Backend)

Python / FastAPI - خادم API عالي الأداء مع قاعدة بيانات MySQL

  • FastAPI مع توثيق تلقائي (Swagger UI)
  • مصادقة آمنة (JWT + OAuth2)
  • خدمات ذكاء اصطناعي متعددة (Chat AI, تحليل الصور)
  • نموذج تنبؤ الوزن (ML - Linear Regression)
  • إشعارات ذكية (مواعيد الأدوية، تذكير بالماء، تحفيز الأهداف)
  • تحليل الأعراض والتنبؤ بالأمراض
  • نظام أهداف ديناميكي متكيف (11 مسار API)
  • مزامنة دورية للبيانات
Python 3.9+ FastAPI MySQL Scikit-learn
⬇ REST API + JSON ⬇

MySQL مع نماذج بيانات تشمل: المستخدمين، الأدوية، الأنشطة، التغذية، الأعراض، الوزن، الماء، المحادثات، المجتمع، الأهداف الديناميكية، والمسابقات

🧠 الذكاء الاصطناعي

تقنيات AI و Machine Learning

VITA يستخدم الذكاء الاصطناعي في عدة مجالات لتقديم تجربة صحية ذكية، مع 4 نماذج تعلم آلة مخصصة.

⚖️

تنبؤ الوزن

نموذج Linear Regression يتنبأ بالوزن المستقبلي بناءً على البيانات التاريخية للمستخدم، مما يساعد في تتبع التقدم وتحقيق الأهداف.

🤖

المساعد الصحي الذكي

نظام محادثة ذكي يجيب على الأسئلة الصحية، يقدم نصائح مخصصة، ويساعد في تفسير الأعراض والنتائج.

🩺

تحليل الأعراض

تحليل متقدم للأعراض المسجلة للكشف عن الأنماط والتنبؤ بالمشكلات الصحية المحتملة قبل حدوثها.

📸

تحليل الصور الطبية

تحليل الصور الطبية المرفوعة باستخدام تقنيات التعلم العميق لتقديم تشخيصات أولية دقيقة.

🎯

التحفيز السلوكي

نظام تنبيهات وتحفيز ذكي يساعد المستخدم على الالتزام بعاداته الصحية من خلال تذكيرات مخصصة.

🔮

الوقاية التنبؤية

تحليل البيانات الصحية للتنبؤ بالمخاطر المستقبلية وتقديم توصيات وقائية مخصصة لكل مستخدم.

📊

تنبؤ الوزن المحسّن (Ensemble)

نموذج تنبؤ متطور يجمع بين Linear Regression و Random Forest و Gradient Boosting لتوقع الوزن المستقبلي بدقة عالية، مع تحليل الاتجاهات والتوصيات.
